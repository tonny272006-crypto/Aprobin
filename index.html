Section 07 // Architecture & Roadmap

4-Phase Engineering & Implementation Roadmap

Phased development plan decoupling mechanical fabrication, embedded motor control, Edge AI classification, and clinical navigation.

Phase 01 // Baseline
Make It Move
Dead-reckoning locomotion with closed-loop gyro heading correction and Bluetooth control.
  • Arduino Uno + Dual DC Motors
  • MPU6050 IMU gyro yaw stabilization
  • HC-05 with 5V-to-3.3V resistor divider
  • Independent motor battery supply
ACCEPTANCE: 5x 3m runs within ±15cm; 10x 90° turns within ±5°.
Phase 02 // Mechanics
Sorting Mechanism
Multi-chamber indexing carousel drum and gravity-drop intake hatch actuation.
  • MG995 metal gear carousel servo
  • Secondary hatch trapdoor servo
  • Dedicated 5V 3A isolated buck converter
  • Calibrated 4-quadrant angles (~60° separation)
ACCEPTANCE: 10 sort cycles per section (40 total) with 0 jams or brownout resets.
Phase 03 // Intelligence
Connect The Pi
Autonomous Edge AI classification via TensorFlow Lite and automatic serial dispatch.
  • Raspberry Pi 3B+ + Pi Camera
  • Quantized MobileNet INT8 TFLite model
  • Internal chute LED ring illumination
  • Hands-free B1–B4 command dispatch
ACCEPTANCE: Item dropped into chute auto-sorts correctly at least 8 out of 10 times.
Phase 04 // Deployment
Full Facility App
Drag-and-drop floor navigation, waypoint route planning, and ultrasonic safety override.
  • Hospital grid layout route planner
  • Sequential F / L / R command buffering
  • Pi 3B+ Wi-Fi access point bridge
  • HC-SR04 ultrasonic collision cutoff
ACCEPTANCE: Autonomous room-to-room waypoint patrol with obstacle auto-halt.
